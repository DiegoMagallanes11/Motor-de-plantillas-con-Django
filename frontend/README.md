# Cine Tecsup — React Lab09

Cartelera académica con ocho películas y ocho componentes funcionales con props,
sin estado ni hooks. Forma parte del repositorio acumulativo del curso.

Desde esta carpeta:

```powershell
npm ci
npm run dev
```

Abrir http://localhost:5173/. Node compatible: 20.19+ en la rama20, 22.12+ en
la rama22, o 24 y posteriores. Se verificó con Node24.15.0.

```powershell
npm test
npm run duel
npm run duel:fixed
npm run build
npm run lint
```

`npm run duel:ai` falla intencionalmente: conserva los seis fallos de las
respuestas originales. `fixed:init` se utilizó antes de corregir la copia;
no lo fuerces sobre los arreglos terminados.

Consulta [LAB09.md](../LAB09.md) para instalación, arquitectura de CSS, props,
casos de error, pruebas, procedencia y conclusiones. La [guía resuelta en Word](../deliverables/lab09/Lab09_Diego_Magallanes_Linares.docx)
incluye capturas reales. Datos y pruebas provienen del [material del docente](https://github.com/Hellscythe25/dae-s09-react-ia),
revisión861176ca6b84f80446928c3fc2484aba2c1dceb0; se conservaron los originales.
Implementación y documentación realizadas con asistencia de Codex.
